✅ Task Management System

A simple and responsive **Task Management System** built to organize daily tasks and exam schedules in one place. It helps users create tasks, set priorities and deadlines, track progress, and receive reminders for upcoming tasks.

📌 Project Overview

The Task Management System provides a clean dashboard to manage daily activities and exam-related tasks. Users can add new tasks, view pending and completed work, filter tasks by category, and stay organized with due-date and reminder featur

✨ Features

- **Add Tasks:** Create tasks with a title, category, priority, and due date.
- **Task Categories:** Separate daily tasks and exams for better organization.
- **Priority Management:** Set task priorities to High, Medium, or Low.
- **Task Status Tracking:** Mark tasks as completed and track pending work.
- **Dashboard Statistics:** View total, pending, and completed task counts.
- **Task Filtering:** Filter tasks by All, Pending, Done, and Exams.
- **Due-Date Management:** Assign deadlines to tasks and exams.
- **Reminder Notifications:** Set reminder times and receive browser notifications when supported and permission is granted.
- **Responsive Interface:** Use the dashboard through a clean, user-friendly interface.
- **Delete Tasks:** Remove tasks when they are no longer needed.
